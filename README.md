# `libascii`

> [!IMPORTANT]
> `libascii` is in active development. The API may change at any time. Use at your own risk!

`libascii` is a general-purpose library in pure Python for creating graphics using ASCII and Unicode characters geared towards games.

## Install
Install via `pip`:

```bash
$ pip install libascii
```

Build from source (if you want to latest [potently broken] dev build):
```bash
$ git clone https://github.com/NNlk05/libascii && cd libascii
$ pip install .
```

## Usage
See the [`libascii` wiki](https://github.com/NNlk05/libascii/wiki) or the demos in `demos/` for usage
