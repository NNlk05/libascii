# `libascii`

`libascii` is a general-purpose library in pure Python for creating graphics using ASCII and Unicode characters geared towards games.

## Install
Install via `pip`:

```bash
$ pip install libascii
```

Build from source (make sure you have `uv` installed):
```bash
$ git clone https://github.com/NNlk05/libascii && cd libascii
$ uv build
$ pip install -e . #TODO: I think this is the right commands but I'm not sure...
```
